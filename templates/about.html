About TruthLens

A machine-learning based fake-news classification project.

About the Project

TruthLens is an academic project designed to demonstrate how Natural Language Processing and Machine Learning can be applied to the classification of news articles. The system analyzes the text entered by the user and generates a machine-learning prediction indicating whether the article is likely to be real or potentially fake.

Project Objective

The main objective of TruthLens is to develop a simple web-based system that demonstrates the use of machine learning for fake-news classification and provides users with an easy interface for testing news text.

Technologies Used

Python Programming language
Flask Web backend framework
Pandas Dataset processing
Scikit-learn Machine learning
TF-IDF Text feature extraction
Logistic Regression Classification algorithm
SQLite Detection history
HTML & CSS Website interface

Model Information

Algorithm: Logistic Regression

Feature Extraction: TF-IDF

Classification: Fake / Real

Test Accuracy: Approximately 98% on the current test split.

Important Limitation

TruthLens provides a machine-learning classification based on patterns learned from its training dataset. It is not a replacement for professional fact-checking or verification from reliable sources.
