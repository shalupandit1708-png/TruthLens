How TruthLens Works

News classification using Natural Language Processing and Machine Learning.

01

News Dataset

The model is trained using the Fake.csv and True.csv datasets containing examples of fake and real news.

02

TF-IDF

News text is converted into numerical features using Term Frequency-Inverse Document Frequency.

03

Logistic Regression

The trained classification model analyzes the text and predicts whether it is likely real or fake.

About TruthLens

TruthLens is an academic fake-news detection project that demonstrates how Natural Language Processing and Machine Learning can be used to classify news content. The system is trained using the Fake.csv and True.csv datasets. It uses TF-IDF for text feature extraction and Logistic Regression for classification. Users can provide a news headline and article, and TruthLens analyzes the content using patterns learned during model training. The prediction should be treated as an ML-based classification rather than a guaranteed factual verdict.
