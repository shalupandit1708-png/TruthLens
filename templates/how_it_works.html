How TruthLens Works

TruthLens uses Natural Language Processing and Machine Learning to classify news text.

01

Enter News

The user enters or pastes a news article into the TruthLens detection box.

02

Text Processing

The news text is processed so that it can be analyzed by the machine-learning system.

03

TF-IDF Feature Extraction

TF-IDF converts the words in the article into numerical features that the machine learning model can understand.

04

Machine Learning

A Logistic Regression classifier trained on labelled fake and real news examples analyzes the extracted features.

05

Prediction

The model produces a classification such as "Likely Real" or "Possibly Fake" along with its model confidence.

06

Save to History

The result is stored in a local SQLite database so previous analyses can be viewed later.

Technologies Used

  • Python
  • Flask
  • Pandas
  • Scikit-learn
  • TF-IDF
  • Logistic Regression
  • SQLite
  • HTML & CSS
